# LeetCode Practice (Kotlin & Java)

A workspace for practicing LeetCode problems in Kotlin & Java, utilizing Google Antigravity and its LeetCode MCP tools.

## Structure
* src/main/kotlin/: Problem solutions in Kotlin.
* src/test/kotlin/: Unit tests for Kotlin solutions (JUnit 5).
* src/main/java/: Problem solutions in Java.
* src/test/java/: Unit tests for Java solutions (JUnit 5).

## Commands
* Run Kotlin tests: ./gradlew test
* Run Java tests: ./gradlew test
* Run specific Kotlin solution: ./gradlew run
* Run specific Java solution: ./gradlew run
